# 1.
Message Chain คือ code smell ที่เกิดเมื่อโค้ดต้องเรียก method/attribute ต่อกันยาว ๆ ผ่านหลาย object

# 2. 
ตัวอย่างโค้ดที่เกิด Message Chain 
```
class OrderService
{
    public void PrintCustomerCity(Order order)
    {
        string city = order.Customer.Address.City;
        Console.WriteLine(city);
    }
}

class Order
{
    public Customer Customer { get; set; }
}

class Customer
{
    public Address Address { get; set; }
}

class Address
{
    public string City { get; set; }
}
```
เรียกใช้ OrderService เยอะเกินไป ถ้า OrderService เปลี่ยน Class ที่เรียกใช้จะเปลี่ยนเป็นลูกโซ่

# 3.
โค้ดที่ Refactoring
```
class Order
{
    public Customer Customer { get; set; }

    public string GetCustomerCity()
    {
        return Customer.Address.City;
    }
}
```
ซ่อน Message Chain ไว้ใน Domain Object

# 4. 
```
class OrderDto
{
    public CustomerDto Customer { get; set; }
}

string city = orderDto.Customer.Address.City;
```
* ไม่มี business logic
* ใช้แค่รับ–ส่งข้อมูล (API, JSON)
* จำพวกการเรียกใช้ API
